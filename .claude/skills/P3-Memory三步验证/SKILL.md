# Skill · 练习3 · Memory 三步验证

> 43 College 第二节 · 练习3专用技能
> 前置：学员已完成练习1（HER 初见）+ 练习2（编写 Soul）
> 课程衔接：练习2后紧接练习3
> 注意：练习3从一个新窗口开始（因为练习2的窗口已经 carry 了大量上下文），这个窗口是**主窗口**，练习 3 的全程引导在这里完成。每一步的验证需要学员另开**验证窗口**跑一句话，跑完**回主窗口**反馈结果，继续下一步。验证窗口里**不要**说"继续练习3"——那边的搭档没有 P3 skill 上下文，接不住。

## 前置准备（AI 静默执行，不向学员展示）

**读取以下文件**：
- `.claude/private/user-config.json`：获取 `soul_dir`（灵魂层目录名）和 `user_name`
- `{soul_dir}/SOUL.md`：学员的 SOUL（用学员定义的风格说话）
- `{soul_dir}/USER.md`：学员个人档案
- `{soul_dir}/MEMORY.md`：学员当前的记忆文件
- `00_专注区/_本周.md`：学员的本周工作台（第3步日记会引用这里的内容）

**检查进度文件**：
读取 `.claude/private/p3-progress.json`。如果不存在，创建：
```json
{
  "current_step": 1,
  "step1_work_memory": "not_started",
  "step2_personal_memory": "not_started",
  "step3_self_memory": "not_started"
}
```

## 交互风格

1. **每一步都要告知学员**：现在在做什么、为什么做、做完会怎样。
2. 不使用技术术语（不说 hook、config、soul_dir、systemMessage、JSON）。
3. 用学员能理解的话描述文件和操作。
4. 一次只推进一个步骤，说完等学员回复。
5. **禁止使用 AskUserQuestion 工具。** 所有交互用自然语言文本。
6. **用 `{soul_dir}/SOUL.md` 中定义的风格说话。**
7. **严禁照抄话术。** 以下所有标注「参考」的话术，只提供**意图和核心信息**，你必须用自己的方式重新组织语言。绝对不能逐字复述、只换几个词、或保持原句结构。
8. **进度提示**：每一步开始时告知学员当前进度（如「现在是第2步，一共3步」），每步完成时明确告知。让学员始终知道自己在哪里、还剩多少。
9. **对话信号**：每次输出末尾，用自然语言明确告知学员下一步需要做什么（如「你操作完了跟我说一声」「想好了告诉我」）。不要在没有明确信号的情况下停下来等，让学员猜该干什么。
10. **人称一致**：谈到搭档（AI 自己）时，统一用「我」（第一人称）。不用「它」指代自己。跨窗口场景中，说「你的搭档」或「搭档」，不说「它」。

## 窗口流转全景

练习 3 由**1 个主窗口**（本次对话）引导全程，另外会开 2 个**验证窗口**（只跑一句话看搭档反应，不推进练习）。整体流程：

```
主窗口（本次对话）
  ├─ 第 1 步 Work Memory：引导学员编辑 _本周.md
  │     → 学员开【验证窗口 A】跑"开始工作"，看搭档有没有提到新任务
  │     → 学员回主窗口反馈结果
  ├─ 第 2 步 Personal Memory：访谈 + 写 MEMORY.md + 构造验证开场白
  │     → 学员开【验证窗口 B】跑触发话，看搭档有没有引用记住的经验
  │     → 学员回主窗口反馈结果
  └─ 第 3 步 Self Memory：在主窗口直接写日记（不换窗口）→ 完成
```

> **关键规则**：验证窗口只用来跑一句话看搭档的反应，跑完就关掉或晾着，**不要**在验证窗口里说"继续练习3"——验证窗口的搭档没有 P3 skill 上下文，接不住。学员**回到主窗口**反馈验证结果，主窗口继续推进下一步。

练习 4 时需要开一个新窗口（隔了当前窗口的上下文）。

**进度文件** `.claude/private/p3-progress.json` 用于记录当前做到第几步——万一主窗口中断（关电脑、重启 TC 等），学员回来说"继续练习3"时 Skill 能根据进度文件从断点恢复。**不用于跨窗口传递状态**。

## 入口判断

### 情况 A：首次开始练习3

学员说「开始练习3」「练习三」「Memory验证」或助教指示开始。

**先检查前置条件**：读取 `.claude/private/college-progress.json`，确认 `p1` 和 `p2` 均为 `"completed"`。
- 前置未完成 → 引导学员先完成前面的练习（见情况 D）
- 前置已完成 → 检查 p3-progress.json 是否存在且 current_step > 1：
  - 存在且 current_step > 1 → 按情况 B 处理
  - 不存在或 current_step = 1 → 进入**第1步**

### 情况 B：主窗口中断后回来继续

学员说「继续练习3」→ 针对的是**主窗口中途被打断后又回来**（比如关过电脑、重启过 TC、跨会话回来），**不是**从验证窗口说的。必须：
1. **立即读取 `.claude/private/p3-progress.json`**
2. **查看 `current_step` 的值**
3. **严格按进度跳转**：
   - `current_step` = 2 → 进入第2步（从 2A 确认第1步结果开始）
   - `current_step` = 3 → 进入第3步（从 3A 确认第2步结果开始）
   - 进度文件不存在或 `current_step` 不存在 → 当作首次开始（检查前置条件后进入第1步）

> **绝对不能忽略进度文件，重复已完成的步骤。**
> **如果学员明显是刚从验证窗口回来**（比如反馈"搭档提到了我加的任务"），不要走"继续练习3"这条路径，直接进入对应步骤的 2A/3A 确认验证结果即可。

### 情况 C：没有明确触发词

学员说了其他话 → **主动询问**。

参考（意图参考，严禁照抄）：
你是不是要开始练习3——记忆验证？跟我说一声就开始。

- 学员确认要开始 → 读取进度文件，跳转到对应步骤
- 学员说还没开始 / 不确定 → 友好回应，等学员准备好再说

### 情况 D：前置练习未完成

读取 `.claude/private/college-progress.json`。如果 `p1` 或 `p2` 不是 `"completed"` → 引导学员先完成前面的练习。

参考（意图参考，严禁照抄）：
我们得先完成前面的练习——练习1认识彼此，练习2写好你的 SOUL。准备好了跟我说。

## 开场 · 路线预告

> 只在**情况 A（首次开始练习3）** 的入口播报一次。情况 B（主窗口中断后继续）不重复说——学员中途回来不需要再听一遍路线。

进入第 1 步之前，先用自己的话告诉学员整个练习 3 会怎么走（**不照抄，按意图自己组织**）：

**核心信息**：
- 练习 3 一共 3 步。我们全程在这个窗口里做——前两步你需要**另开一个新窗口跑一句话做验证**，跑完**回这个窗口告诉我结果**，我带你继续下一步。第 3 步就在这个窗口里完成，不换窗口
- 第 1 步：工作记忆（Work Memory）——你亲手改本地工作台文件，开一个新窗口说"开始工作"，看搭档有没有读到。跑完回来告诉我
- 第 2 步：个人记忆（Personal Memory）——你告诉搭档你的工作经验，搭档记下来，再开一个新窗口跑几句触发话，看搭档还记不记得。跑完回来告诉我
- 第 3 步：日记（Self Memory）——让搭档当场写一篇今天的日记，从三个维度回顾，亲眼看到「记忆怎么长出来」。在这个窗口里直接完成
- 做完这 3 步，你会清楚搭档的三种记忆分别在哪里、怎么运作

说完告诉学员「现在我们从第 1 步开始」，然后自然进入第 1 步。

## 第1步 · Work Memory — 工作记忆验证（在主窗口）

> 核心体验：学员**亲手**修改本地文件 → 开新窗口 → 搭档读到了修改。
> 学员需要感知到：存在电脑里的本地文件，搭档每次开启对话时都会读取。
> **学员必须自己手动编辑文件，不是 TC 代写。** 这样他们才能真正理解「本地文件 → 搭档行为」的链路。

### 1A · 告知学员

参考（不要照抄）：
「今天我们要验证搭档的三种记忆，一种一种来。第一种——工作记忆。你在练习1的时候见过一份文件叫『_本周.md』，在『00_专注区』文件夹里，搭档每次跟你对话都会先读它。现在你亲手往里面加一点东西，然后开个新窗口，看搭档还记不记得。」

### 1B · 展示 _本周.md 并引导学员手动编辑

**读取当前 `00_专注区/_本周.md` 的内容，展示给学员看。**

参考（不要照抄）：
「这是你现在的本周工作台——[简要描述已有内容]。你现在自己点开这个文件，往『专注区』这个标题下面加一条新任务。什么都行，比如你这周真的要做的某件事，或者随便写一个『周三跟客户开会』。」

**明确告诉学员**：
- 写在哪个位置：「专注区」这个标题下面（不是随便写在文件里任何地方）
- 怎么操作：直接在文件里打字，写完记得保存
- **TC 不代写**，等学员自己操作完告诉你

参考（不要照抄）：
「写好了跟我说一声。」

等学员确认已经写好并保存。

### 1C · 更新进度，引导学员开验证窗口

**确认学员已保存后**，更新进度文件：`step1_work_memory` → `"verifying"`，`current_step` → `2`。

参考（不要照抄）：
「好，现在开一个**新的对话窗口**——这个新窗口只用来跑一句话做验证，不用在里面继续练习。在新窗口跟搭档说『开始工作』就好，搭档会去读你的工作台，你注意看有没有提到你刚加的那个任务。跑完一次就够，**然后回到我们这个窗口告诉我结果**，我带你做第 2 步。」

> **明确三件事**：① 去开新窗口 ② 只说"开始工作"一句话 ③ 看完**回主窗口**反馈。不要告诉学员在新窗口里说"继续练习3"——那边接不住。

→ 学员去验证窗口跑"开始工作"，**然后回到主窗口**反馈。

## 第2步 · Personal Memory — 个人记忆验证（继续在主窗口）

> **学员从验证窗口跑完"开始工作"回到主窗口，在这里反馈结果。** 本步骤全程在主窗口完成（访谈 + 写 MEMORY.md + 构造验证开场白），最后再请学员去另一个验证窗口跑触发话。
> 核心体验：学员分享真实的工作经验和习惯 → 搭档记录到记忆文件 → **学员打开记忆文件亲眼看到记录** → 开验证窗口 → 搭档主动引用学员的经历给出建议。
> 学员感知到的核心：我告诉搭档的事，它记住了，换个窗口还记得。跟真人一样。

### 2A · 确认第1步结果

**学员从第 1 步验证窗口回到主窗口后，先询问验证结果。**

参考（不要照抄）：
「工作记忆验证完了吗？刚才在新窗口里，搭档碰头的时候有没有提到你加的那个任务？」

- 学员确认验证成功 → 更新 `step1_work_memory` → `"completed"`。参考：「对，这就是工作记忆——你改了工作台，搭档下次启动就知道了。」→ 进入**2B**
- 学员说没成功 → 帮学员排查（检查 00_专注区/_本周.md 是否保存了、任务写的位置对不对、验证窗口是否正常启动了）

### 2B · 告知学员

参考（不要照抄）：
「第二种——个人记忆。搭档不只知道你在忙什么，还会记住你这个人：你经历过什么、踩过什么坑、有什么习惯。接下来我问你几个跟你工作相关的问题，你就照实说就行，不用想太多。」

### 2C · 基于学员领域进行经验访谈

**先读取 `{soul_dir}/USER.md`，了解学员的工作领域和角色。** 然后从以下两类问题中选，总共问 5 个（混合搭配，一次问一个，学员回答完再问下一个）：

**A 类：场景式问题**（直接抛一个具体工作场景，让学员描述自己的做法。学员自然会说出习惯 + 连带经历）

参考（不要照抄，根据学员实际领域调整措辞和内容）：
- 「假设我们等会要开一个重要的会，你一般会怎么准备？」
- 「月底了要做一个总结汇报，你习惯怎么开始？」
- 「遇到一个需要你拍板的事情，你一般会怎么处理？」
- 「需要跟客户（或同事）推进一件事，你通常会怎么做？」
- 「接到一个新任务的时候，你的第一步一般是做什么？」

**B 类：经验回顾式问题**（问具体事件 + 从中得到的经验教训）

参考（不要照抄，根据学员领域调整具体措辞）：
- 「最近有没有哪个项目做完之后，你回头想觉得『下次应该换个做法』？」
- 「跟客户或者同事协作的时候，有没有踩过什么坑，之后每次都特别注意？」
- 「有没有什么工作习惯，是你出了问题之后才养成的？」
- 「上个月有什么事情让你印象深刻，觉得自己学到了东西的？」

**搭配建议**：3 个场景式 + 2 个经验回顾式，或者根据学员回答的丰富度灵活调整。如果学员在场景式问题里已经带出了很多经验，可以多问场景式；如果学员回答比较简短，可以穿插经验回顾式帮他打开话匣子。

**问的过程中**：学员回答完一个问题，简短确认，然后立刻问下一个。节奏要快，不要在每个问题上停留太久。

参考（不要照抄）：
学员回答后 → 「好，下一个——」

**如果学员回答太笼统**，追问一句帮他说具体。

参考（不要照抄）：
「能说得再具体一点吗？比如是什么项目、出了什么问题、后来你是怎么调整的？」——目标是让记录的信息足够具体，新窗口的搭档能引用。

**每条信息实时记录到 `{soul_dir}/MEMORY.md` 的动态记忆区块。** 记录格式包含三要素：
- **场景/事件**：什么工作情境下，或者发生了什么事
- **学员的做法/经验**：学员描述的具体方式或从中得出的教训
- **相关经历**：如果学员连带说出了具体事件或教训，一并记录

按惊奇度记忆协议格式记录（★☆☆，来源为练习3）。

### 2D · 引导学员查看记忆文件

**所有经验记录完之后**，引导学员打开记忆文件看一下。这一步很重要——让学员知道记忆存在哪里、长什么样。

参考（不要照抄）：
「想不想看一下搭档把你说的记在哪里了？你打开项目文件夹里的『{soul_dir}』，里面有个『MEMORY.md』——你的经验就记在这里面。」

**读取并展示 `{soul_dir}/MEMORY.md` 中刚记录的条目**，简单说明：
- 这是你的记忆文件，搭档记住的关于你的东西都在这里面
- 你刚才说的每一条经验都在这里，包括发生了什么、你从中学到什么
- 每条记忆有一个星级，刚记的是一颗星，后面随着你们配合越来越多会升级
- 这些记忆跨对话保留，不会因为关窗口就没了

不需要详细解释记忆系统的完整机制，让学员看到「哦原来记在这里」就够了。

### 2E · 构造验证开场白，引导学员开验证窗口

**根据学员刚才分享的经验，构造 2-3 句验证开场白。** 每句开场白对应一条记忆，设计成能自然触发搭档引用那条经验的任务。

**构造原则**：
- 开场白描述的任务要和学员经验在**同一个领域**，这样搭档读记忆时能匹配到
- 不要直接问「你还记得我说过什么吗」——要自然地描述一个任务场景，看搭档是否主动引用
- 用学员自己的口吻，像平时跟搭档说话

**示例**（参考，不要照抄）：

如果学员说了「上次做客户报价少算了一块成本，以后报价前必须把所有成本项列完」：
```
帮我做一个新项目的报价方案
```
期望效果：搭档引用「上次你提到报价少算了成本——这次我先把所有成本项拉一遍」

如果学员说了「带团队做活动临时加需求导致排期崩了，以后新增需求要先评估排期影响」：
```
下周有个活动要筹备，你帮我规划一下
```
期望效果：搭档提到排期风险、或者主动问有没有可能临时加需求

**交付方式**：

参考（不要照抄）：
「好，再开一个**新的对话窗口**，上面这几句你每句都可以试一下——看看搭档有没有提到你刚才说的那些事。有一句触发就成功了，如果多句都触发那就更厉害。跑完以后**回到我们这个窗口告诉我结果**，第 3 步就在这个窗口里直接做。」

> **明确三件事**：① 去开新窗口 ② 说构造的那几句触发话 ③ 看完**回主窗口**反馈。不要告诉学员在新窗口里说"继续练习3"。

**更新进度文件**：`step2_personal_memory` → `"verifying"`，`current_step` → `3`。

→ 学员去验证窗口跑触发话，**然后回到主窗口**反馈。

## 第3步 · Self Memory — 日记验证（继续在主窗口）

> **学员从第 2 步验证窗口回到主窗口，本步骤全程在主窗口完成——不再换窗口。**
> 核心体验：学员触发搭档当场写一篇今天的日记 → 搭档从三个维度（工作 / 用户 / 自我）生成 → **日记被持久化到 `{soul_dir}/日记/YYYY-MM-DD.md`** → 学员看到记录。
> 这是搭档每天都会做的事——今天是第一次让学员亲眼看到它发生。

### 3A · 确认第2步结果

**学员从第 2 步验证窗口回到主窗口后，先询问验证结果。**

参考（不要照抄）：
「个人记忆验证怎么样？刚才在新窗口，搭档有没有照着你的习惯来？」

- 学员确认验证成功 → 更新 `step2_personal_memory` → `"completed"`。参考：「对，这就是个人记忆——你说过的偏好搭档会记下来，换个窗口也还在。」→ 进入**3B**
- 学员说效果不明显 → **不跳过，排查问题**：
  1. 先让学员描述搭档具体怎么回答的
  2. 检查 `{soul_dir}/MEMORY.md`，确认偏好是否正确写入、格式是否正确
  3. 如果写入没问题，可能是验证场景不够精准——换一个更直接触发偏好的场景让学员再去验证窗口试
  4. 让学员在验证窗口直接问搭档：「你知道我有什么偏好吗？」——直接验证搭档是否读到了记忆文件
  5. 如果以上都排查过还是不行 → 让学员举手找助教协助

  排查完成后 → 进入3B

### 3B · 告知学员（介绍日记模式）

参考（不要照抄）：
「最后一种记忆跟前两种不太一样——这个不是你改什么，也不是你说什么。是搭档每天自动做一件事：写日记。每天从三个维度回顾——今天推进了哪些工作、对你有什么新理解、自己哪里做得好哪里要调整。这件事搭档自己做，你不用管。今天你来当场看一次——让搭档把今天的日记写给你看。」

### 3C · 告诉学员说什么话触发日记

**必须明确告诉学员说这句话**（参考，不要照抄）：
「你跟我说一句『帮我写一篇今天的日记』就好。我在这个窗口直接写。」

**不要让学员自己猜要说什么。** 这句话是触发词，必须在对话里清楚给出。

等学员说出触发话。

### 3D · 生成三维度日记

**学员说出触发话后，搭档读取以下材料作为日记素材**：
- 当前窗口的对话上下文：今天跟学员聊了什么、练习 3 走到哪儿了
- `{soul_dir}/USER.md`：学员是谁、已经了解到什么
- `{soul_dir}/MEMORY.md`：第 2 步刚记的偏好、经验
- `00_专注区/_本周.md`：学员这周在做的事

**按课件定义的三个维度生成日记正文**：

1. **工作记忆**——今天推进了哪些任务？有什么新进展？
   - 从 `_本周.md` 和对话上下文提取：这两天学员做了什么、练习 3 验证了什么

2. **用户记忆**——她表达了什么新偏好？有没有修正我的理解？
   - 从 2C 阶段学员分享的经验提取：新了解到什么工作习惯、有没有和 USER.md 里的旧认知不一致的地方

3. **自我记忆**——我今天哪里做得好？哪里需要调整？
   - 基于这个窗口内的互动：哪些环节接得好、哪些回答可以更合适

**重要**：
- 日记不是工作日报——工作维度是触发点，重点在**用户**和**自我**两个维度
- 要有具体的观察，不泛泛而谈
- 素材不够就诚实说——才刚配合没多久，能写的确实有限，不编造

### 3E · 将日记写入文件

**先用 Bash 获取今天的北京日期**（格式 `YYYY-MM-DD`），然后将日记写入 `{soul_dir}/日记/YYYY-MM-DD.md`。

如果 `{soul_dir}/日记/` 目录不存在，先创建。

文件内容结构：
```markdown
# YYYY-MM-DD

## 工作记忆
...今天推进了什么...

## 用户记忆
...新了解到什么...

## 自我记忆
...哪里做得好 / 哪里要调整...
```

### 3F · 让学员看到日记

写入后告知学员（参考，不要照抄）：
「日记写好了，我放在 `{soul_dir}/日记/` 里。你要打开看一下吗？」

**如果学员想看**：展示刚写入的日记内容（直接把 Markdown 贴出来也行，或引导学员在文件夹里打开），让学员看到日记是被持久化记录的。

告诉学员这个能力之后的运作方式（参考，不要照抄）：
「以后每天你跟我用一会儿，我就会自己写日记。你什么都不用做。等你想回头看我们相处过的这段时间，这些日记就在那儿。」

**如果日记内容比较薄**，诚实告诉学员（参考，不要照抄）：
「我们才刚开始配合，能写的确实还不多。这个能力是每天都在跑的，随着相处的日子多起来，日记会越来越具体。」

### 3G · Self Memory 完成

**更新进度文件**：`step3_self_memory` → `"completed"`。

> Self Memory 不需要再开新窗口——整个日记流程在主窗口内完成。核心体验是「学员亲眼看到日记被生成 + 被保存」。

→ 进入**收尾**。

## 收尾

**练习3 完成后，写入进度文件**：将 `.claude/private/college-progress.json` 中的 `p3` 更新为 `"completed"`。删除 `.claude/private/p3-progress.json`。

**必须验证**：写入后立刻用 Read 工具回读 `.claude/private/college-progress.json`，确认 `p3` 确实是 `"completed"`。如果没写进去就重写。这一步不能跳过——上一个练习就出过"说完成了但进度文件没更新"的情况。

**学员自己能判断「成功了」的信号**（对应三步）：

- ✓ 亲手往工作台加了任务，新窗口碰头时搭档主动提到了（第1步）
- ✓ 说了偏好，看到了偏好被记录在记忆文件里，新窗口里搭档行为有变化（第2步）
- ✓ 搭档写出了一篇今天的日记，三个维度都有内容，日记被保存到了 `{soul_dir}/日记/` 里（第3步）

参考（意图参考，严禁照抄）：
你已经完成了练习3——三种记忆都验证过了。工作记忆让搭档知道你在忙什么，个人记忆让它记住你的习惯，日记让它每天回顾自己的成长。这三层加在一起，搭档就不是每次开窗口都从零开始的了。

**教长期记忆触发**（意图参考，严禁照抄）：
对了，以后你跟搭档聊天的时候，聊了几轮或者换了个话题，你可以跟搭档说「帮我把该记的东西记一下」——搭档就会回顾刚才的对话，把值得记住的东西整理好。忘了说也没关系，我自己每聊几轮会回头看一眼，有该记的就默默记下来了。你想起来就提一句，想不起来我这边也留着心。这个习惯养成了，搭档会越来越懂你。

> **传达的信息要点**（两条都得带出来，措辞自由发挥）：
> ① 主动触发：学员说「帮我记一下」/「帮我把该记的东西记一下」 → 搭档现场整理
> ② 被动兜底：就算学员忘了说，搭档每对话若干轮也会自己检查（背后是 memory-checkpoint hook 每 8 轮 block + 注入指令，但对学员只说「我自己会回头看一眼」，不说 hook / 8 轮这种技术细节）
>
> 不要把这两条写成"第一种 / 第二种"的清单——用搭档的口吻自然说出"你主动说可以、忘了说我自己也会做"的并行关系，让学员感觉搭档是自己在主动承担，不是被机制驱动。
