风格趋势总结

从 JYSK 现有品类中可以提炼出清晰的设计语言体系。

🎨 主色调

Beige 米色 — 基底色 Apple Green 苹果绿 — 清新感 Dusty Grape 淡紫灰 — 高级感 Pale Khaki 浅卡其 — 自然风 Blue/White 蓝白 — 经典北欧 Floral 花卉 — 装饰语言

🧱 核心材质

Stoneware 炻瓷 — 质感担当 Acacia 金合欢木 — 自然元素 Glass 玻璃 — 日常线主力 Natural 自然色釉 — 北欧核心

📐 设计策略洞察

  • ✦ 同系列跨品类复用设计元素（EMIL 花卉从碗延伸到马克杯和分餐盘）
  • ✦ 低端用清仓/折扣引流（ELIAS -69%、FERDUS -33%），高端用 EDLP 稳定价格预期
  • ✦ 自然色系 + 炻瓷 = 北欧风品质感的成本效率组合
  • ✦ Summer Sale 期间用大幅折扣清理库存，为秋季新品腾空间

销售机会与开发方向

基于品类覆盖、价格带分布和竞争格局的综合判断。

🫖

茶具套装品类空白

JYSK 有 DETMER 浓缩杯/咖啡杯和 MATHIAS 茶叶盒，但缺少完整的茶壶+杯碟套装。这是中端价位（£15-25）的明显缺口，尤其在英国市场茶具需求稳定。

高潜力
🧈

早餐/黄油小件

黄油盘、奶盅、糖罐、蛋杯等早餐场景小件完全缺失。这类产品单价低（£2-5）、毛利率高，且是建立「一站式厨房品牌」认知的必要品类。

高潜力
🍶

炻瓷系列延伸

MALIK 和 DETMER 已证明炻瓷 stoneware 的接受度。建议在同一材质体系下增加水壶、沙拉碗、烘焙碟等跨场景单品，做强「炻瓷矩阵」。

中潜力
🎄

季节性/限量系列

目前仅有 HILMER 棕榈树马克杯作为季节限定。圣诞节、春季花卉、秋季大地色等季节性主题系列能创造紧迫感、拉动复购，且适合做 gift set 组合。

高潜力
📦

Gift Set 礼盒化

现有产品以散卖为主。将 EMIL 花卉碗+马克杯+分餐盘打包为 gift set，单价可从 £7.50 提升至 £10-12，客单价提升 30-50%。适合节日送礼场景。

高潜力
🪵

天然木系列扩展

SIGVART 砧板和 MATHIAS 茶叶盒是天然木系列的仅有两款。增加木制沙拉碗、面包板、餐具架，可形成完整的「自然厨房」子品牌线，与北欧风高度契合。

中潜力
🔪

厨房工具加深

砧板、隔热垫、研磨器已有，但缺少量杯、搅拌碗、滤网、开瓶器等基本工具。这些产品单价低、频次高，是提升连带购买率的利器。

中潜力
🌍

高端线品牌化

SIGURD 和 NOR 系列已经占据 £13.50-17.50 价格段，但缺少明确的「高端子品牌」叙事。建议用独立命名和专属包装强化品质感知，切入 gift / 婚庆市场。

中潜力
